# Plan: pay down eval debt on the dev split (approved in chat, 2026-11-10)

The developer gave a budget of 40 real model calls and asked for the plan to be prepared and executed.

## Scope
- **No model calls:** `eval_verify`, `eval_localize`, `eval_retrieve`. These are SymPy rules and a local embedding model. Their
  last results are from Oct 27 to Nov 2, and the code has changed since.
- **Model calls:** `eval_hint` (one hint call and one judge call per case), the component that changed most since its Oct 27
  run.
- **Not in this budget:** `eval_parse_input` (about 45 calls for `--limit 15`) and `eval_orchestrator`. The orchestrator has no
  dev dataset yet, only unreviewed candidates in `evals/datasets/review/`, and building one is a data choice for the developer.
  Its scenario replay costs several calls per turn.

## Budget control for `eval_hint`
- A model call can be retried once on invalid output, so one run cannot be strictly capped. The run is staged instead.
  - **Stage 1:** `--limit 8`, 2 cases per level and 16 calls nominally.
  - The real number of calls is counted from new cache entries plus retry warnings in the log.
  - **Stage 2:** `--limit 16`, but only if stage 1 leaves at least 20 calls. `sample_by_level` takes cases in turn over the
    levels, so the first 8 cases are the same and come from the cache. Stage 2 adds 16 calls nominally.
- Stop as soon as the count reaches 40.

## Reporting
- Each run writes its result file under `evals/results/<component>/`.
- Compare with the previous file: a drop of more than 2 percentage points is a REGRESSION.
- Show 3 to 5 failures.
- Add one line per component to `docs/crisp_dm_log.md` under Evaluation.
- Commit the results and the log on `chore/eval-debt-2026-11-10` and open a PR. No code or prompt changes in this task.

## Known limits
- `eval_hint` has no reply or clarifying-question cases, and few "balance" counterexamples. It checks for regressions overall; it
  does not directly test the fixes in #100 and #101.
- The judge is the same model as the hint writer.
- 16 of 60 dev cases is a subset, and the result file says so.
