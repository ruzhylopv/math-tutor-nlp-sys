# Plan: a step log with timings in the chat (approved 2026-11-02)

Follows `2026-10-28-m7-progress.md`. Problem: the status box only changed its title, so it showed
"Reading your message…" for ~20 s (parse_input is a slow LLM call) and stayed empty inside.

- `ui.send_stream` yields `StepStarted(node, label)` when a task starts and `StepFinished(node, label, seconds)` when
  that task's result arrives (matched by task id, timed with `time.monotonic()`), then the final `TurnView`.
  Every node run is logged, a repeated node once per run. `Progress` is removed.
- A node without a label in `PROGRESS_LABELS` is shown by its own name. Labels added for `diagnosis`, `classify`,
  `finish_diagnosis`.
- Each step time is also written to the log (`logger.info`).
- `app.py`: the status title shows the running step; each finished step appends `✓ <label> — 1.2s`; the title ends as
  `Done in 65.2s` / `Failed after …`. The last turn's log is kept in `session_state.step_log` and shown as an expander
  after the rerun; it is not checkpointed, so older messages have no log. New chat and Switch name clear it.
- No eval: UI only.
