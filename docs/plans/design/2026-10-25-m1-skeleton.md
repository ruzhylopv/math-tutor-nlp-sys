# Plan: M1 skeleton (approved 2026-10-25)

Goal: a graph of stub nodes that compiles, draws and passes tests, with config, an LLM client for
OpenRouter and a shared eval runner. No real logic. Roadmap: `docs/plans/design/2026-10-25-roadmap.md`.

## Decisions (from the developer)
- Dependency swap approved: remove `langchain-anthropic`, add `langchain-openai` (OpenRouter is
  OpenAI-compatible). The OpenRouter base URL and structured-output behaviour are checked against its docs and a
  real call (`scripts/check_llm.py`) before anything is hard-coded.
- The API key variable is `OPENROUTER_API_KEY` (replaces `LLM_API_KEY`). The model name comes from `MODEL_NAME` in
  `.env`; no model is hard-coded. The free model is still to be chosen.
- `finish_diagnosis` is exempt from the eval-script rule: one line added to CLAUDE.md. It still has unit tests.
- Locations: `src/tutor/llm.py` (LLM client), `evals/runner.py` (shared eval runner).
- This plan stands in for the per-node plan that the `add-node` skill asks for in step 1.

## Stack
0. `chore/m1-plan`: this plan, the CLAUDE.md exemption, decisions, and the roadmap restored to `main`
   (PR #19 merged into the `docs/design-gaps` branch after PR #18 had merged, so it never reached `main`).
1. `feat/state-models`: `src/tutor/state.py` (`TutorState`, `Step`, `StepVerdict`, `Decision`, `Misconception`) and
   tests.
2. `feat/config-llm`: `src/tutor/config.py`, `src/tutor/llm.py`, `scripts/check_llm.py`, `.env.example`, the
   dependency swap, tests without network.
3. `feat/eval-runner`: the shared eval runner `evals/runner.py` (dataset path, JSONL loading, `--split`, result file per
   the `run-eval` skill) and its tests. Moved before the stubs because every node's eval stub uses it.
   `evals` is made first-party for ruff and importable for pytest (`pythonpath = ["."]`).
4. `feat/diagnosis-stubs`: stubs for `parse_input`, `classify`, `verify`, `localize`, `retrieve`,
   `finish_diagnosis`, their prompts (LLM nodes), unit tests, eval stubs, and the diagnosis subgraph.
5. `feat/main-graph`: stubs for `hint` and the orchestrator, the main graph, `scripts/draw_graph.py`, tests.

Each PR: the review loop (2 passes; superseded 2026-10-27 by one review pass, a fix only for P0/P1: docs/plans/workflow/2026-10-27-single-review-pass.md), the PR template, a CRISP-DM entry and decisions updated.

## Exit criteria
The graph compiles and exports Mermaid; ruff, mypy and pytest pass; stub runs reach the end on every route.
